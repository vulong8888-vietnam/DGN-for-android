Chưa mở file .dgn
Đọc & sửa file địa chính .dgn Bấm “Mở file” và chọn file DGN (định dạng V7 – MicroStation/Famis). Chạm để chọn thửa/đối tượng, kéo để di chuyển, hai ngón để phóng to.

Ô để trống = giữ nguyên. Áp dụng cho đối tượng đang chọn.

Drop (phá nhóm / tách)
