# DGN Địa chính (Android)
1. Tạo repo GitHub mới, upload toàn bộ nội dung thư mục này (giữ cả thư mục .github).
2. Vào tab Actions → Build APK → chờ chạy xong (~5-8 phút), hoặc bấm Run workflow.
3. Mở lần chạy → mục Artifacts → tải dgn-diachinh-apk (file zip chứa app-debug.apk).
4. Chép APK vào điện thoại, cho phép cài từ nguồn không rõ và cài đặt.
Nút Lưu sẽ mở bảng chia sẻ của Android: chọn Tệp/Drive/Zalo... để lưu file .dgn.
